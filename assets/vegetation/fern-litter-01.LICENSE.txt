Fern litter derivative from Poly Haven fern_02 (https://polyhaven.com/a/fern_02), CC0-1.0 (https://polyhaven.com/license).
The extracted connected frond components retain source UVs, normal map, and roughness map. A PCA longitudinal axis is projected into the source-normal tangent plane; the area-weighted source sheet normal and that axis define the blade-face frame, so true transverse width stays in the soil plane while curl follows local Y. Geometry is rooted, uniformly normalized for native soil projection, and retains 35% of source out-of-plane pinna curl. Base-color RGB is an authored muted dry-brown remap from source linear luminance. The embedded base-color alpha uses the pinned Poly Haven 2K 16-bit alpha map, copied sample-for-sample into RGBA16; rendering may quantize it to RGBA8. The result is an optical dead-frond proxy, not measured dead tissue.
