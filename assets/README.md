# Prototype visual assets

This directory contains temporary visual assets for the Bevy client:

- `textures/khepri-surface-v1.png` — hot volcanic Khepri surface;
- `textures/janus-surface-v1.png` — cold rocky Janus surface;
- `textures/orthea-surface-v1.png` — cold high-mass Orthea surface;
- `textures/pelagos-surface-v1.png` — oceanic Pelagos surface;
- `textures/thessa-surface-v1.png` — Thessa moon surface;
- `textures/thessa-surface-v2.png` — deterministic 16K Thessa v0.2 texture
  generated by `thessa-worldgen-rocky` with `export-client-texture`, recipe
  seed `7`, and the streaming PNG encoder. It can be regenerated; v1 is kept
  as a rollback option;
- `textures/borea-surface-v1.png` — icy/basaltic Borea surface;
- `textures/nereid-atmosphere-v1.png` — warm Nereid gas-giant bands;
- `textures/vesper-atmosphere-v1.png` — cold Vesper gas-giant bands.

The v1 maps were generated with ImageGen on 2026-09-07 from prototype
descriptions. They are not physically accurate surface maps and are not part
of the source-code MIT/GPL boundary. Before a public release, record a separate
license and provenance entry for every asset.

The Thessa v2 texture comes from the deterministic world generator, not
ImageGen. It is shared by the system map and pilot view.

Instrument vector icons live in `ui/flight/`: original SVG sources and 4x PNG
exports. They are GPL-3.0-or-later; the client applies interactive-state
colors.
