# HUD font

`NotoSans-Regular.ttf`: Noto Sans, version 2.015, unmodified from the local
`noto-fonts` package. Embedded copyright: Copyright 2022 The Noto Project Authors.

Source: https://github.com/notofonts/latin-greek-cyrillic
License: SIL Open Font License 1.1, reproduced in `OFL.txt` from that source.
The font is independent of the game's GPL license. Flight vector symbols are
geometric UI elements and do not depend on font glyph coverage.

The native terrain viewer's optional egui HUD embeds the same font; no toolkit
default font bundle is required. Include this attribution and `OFL.txt` with
distributions of either client that embed the font.
