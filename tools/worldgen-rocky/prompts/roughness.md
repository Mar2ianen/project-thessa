# Roughness (grayscale, 0 = smooth)

- `#000000` = mirror-smooth: ice, calm water, glassy lava
- `#404040` = packed sand / old lava plains
- `#808080` = generic rock (default)
- `#C0C0C0` = rubble / crater ejecta
- `#FFFFFF` = jagged peaks / fresh fracture

Smooth large areas; detail noise is added procedurally, keep base clean.
Follows biomes: ice always dark, lava fields bright except glassy flows.
