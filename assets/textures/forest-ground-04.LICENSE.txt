forest-ground-04.bin.gz is a packed native 1024x1024 material swatch, not project code.
It contains sRGB reflectance RGB8, linear roughness R8, and relative height R16.
The importer verifies the source PNG checksums and preserves native RGB8,
roughness R8 and height R16 samples with a deterministic gzip header. Runtime uses
the existing flate2 dependency; Pillow and NumPy are offline tooling only.
Reproduce with tools/worldgen-rocky/import_ground_detail.py; exact download URLs
and hashes are recorded in forest-ground-04.provenance.json and the surface-showcase evidence.

This is an authored optical proxy for soil/gravel/organic debris, not measured
Thessa geology, botanical taxonomy, collision geometry or sediment inventory.
The renderer uses an explicit 3.15 m swatch width and 0.060 m relative height
range as rendering priors, not a claim about the scan's calibrated dimensions.

Opt-in runtime material processing applies a continuous authored humus/mineral
reflectance and roughness transfer before linear-light mip averaging. This
leaves the packed CC0 source unchanged; it is not measured mineral taxonomy.
The transfer runs at native resolution before runtime linear-light mip averaging.
The old 512x512 downsample is superseded by WORLD42 (doc 77); GPU residency
budgets and the second mud/litter scan's 512x512 source are unchanged.
