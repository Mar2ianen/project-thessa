# Flight instrument icons

Original Project Thessa vector artwork, GPL-3.0-or-later.
24-unit grid, 1.6-unit rounded strokes. White masters are tinted by the UI;
active controls also have a bright frame and a separate state light.
SVG files are the editable sources. PNG files are 4x exports for Bevy.

Regenerate an export: `rsvg-convert -w 96 -h 96 -o name.png name.svg`.
