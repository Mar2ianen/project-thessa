- Назначение: импортируемый visual mesh North American X-15, используемый

- Источник: Sketchfab, модель **North American X-15 Plane**, автор cmoreau:
  https://sketchfab.com/3d-models/north-american-x-15-plane-bf491206ba844282949734b48b938c53
- Лицензия: CC BY 4.0. Обязательная атрибуция находится рядом с бинарным
  ассетом в `north_american_x-15_plane.LICENSE.txt`.
- Импорт очищен от служебных camera/light/Cube-объектов исходного viewer-
  архива; геометрия и текстуры модели сохранены.

### Оси импортированной сцены

В **самом GLB** нос направлен по `−X`, верх (кабина и спинной киль) по
`+Y`, размах по `Z`. Два корневых узла содержат только масштаб, без поворота.
Blender при импорте переводит glTF Y-up в свой Z-up: его мировые оси нельзя
переносить обратно в Bevy как оси исходного файла.

`x15_asset_to_craft_rotation()` переводит `−X → +Y`, `+Y → −Z`, `+Z → +X`
в локальных координатах родителя модели. Затем `render_orientation()`
применяет физическую ориентацию и перевод Z-up → Y-up. Таким образом, нос
совпадает с физическим `+X`, верх — с физическим `+Z`, размах — с `+Y`.
Навбол получает ту же физическую ориентацию без поправки на ассет.

Регрессионный тест проверяет всю цепочку **включая дочерний поворот GLB**
для начальной, тангажной, креновой и составной ориентаций. Старый тест
проверял только родителя и пропускал неверный поворот самой модели.
